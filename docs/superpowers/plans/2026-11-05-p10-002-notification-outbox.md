## Schema

* NotificationOutboxRow maps to public.notification_outbox. Use an internal generated UUID rowId PK. Immutable public intent fields are intentId, organizationId, workspaceId, storeId, connectionId, externalStoreId, recipientUserId, eventId, eventState, eventRevision, channel, decisionRunId, route, eventType, severity, createdAt, notBefore, evidenceId, evidenceVersion, evidenceHash, entityKind, entityId (nullable only for STORE), definitionVersion and baselineVersion (nullable). V1 schemaVersion is a literal on reconstruction. The reference and summary reuse row binding and eventType. Keep strings opaque, including evidence version/hash, with the actual ExternalId checks. Normalize the allowlist into columns so raw evidence, prompt, arbitrary metadata, contact data or a fabricated second binding has nowhere to go. Enforce the exact eventType/entity matrix from validEntity, including SYNC_FAILURE connection equality, and the existing enum sets. Internal columns are connectionGeneration (current nonnegative PlatformConnection.generation at enqueue), status, attempt, nextAttemptAt, leaseToken, leaseUntil, deliveredAt. No free-form error text.
* Compound FK (connectionId,organizationId,workspaceId,storeId,externalStoreId) to public."PlatformConnection"(id,organizationId,workspaceId,storeId,externalStoreId) transitively binds Store/Workspace. FK (organizationId,recipientUserId) to public."OrganizationMember"(organizationId,userId). RESTRICT delete/NO ACTION update. Workspace eligibility is dynamic under the existing tenant rule below. An unconditional WorkspaceMember FK incorrectly excludes an active OWNER/ADMIN with inherited workspace access. No FK to mutable current event/decision/evidence records. P10-003 verifies authoritative current inputs separately.
* Natural UNIQUE (organizationId,workspaceId,storeId,connectionId,externalStoreId,eventId,eventState,eventRevision,recipientUserId,channel); separate UNIQUE (organizationId,workspaceId,storeId,connectionId,externalStoreId,recipientUserId,intentId) for scoped mark-read/intent resolution. Exact deterministic text equality (C collation for identity strings). Stable intent identity excludes title/severity/route/run/clock/attempt/generation. Use createNotificationIntentKey on the validated scalar identity when returning the DTO. Do not store/index client-supplied JSON dedupKey or grant authority by its possession. Same event revision with only severity changed deduplicates; a new routed revision may generate a new intent.
* Five tenant identifiers including recipient are ASCII 1..128 each. External IDs are 1..256 UTF-16 code units, up to 768 UTF-8 bytes each (BMP three-byte characters are worst case, astral uses two units). Scope + externalStoreId + eventId or intentId tops out at 640 + 1536 = 2176 string bytes, plus short literal state/channel, bigint and bounded tuple/alignment overhead, below the standard PG16 8 KiB B-tree limit (~2704 bytes). Never add another wide opaque field as an included/index key. Use notification-local immutable checks for TenantId regex, ECMAScript trim/forbidden controls and UTF-16 units, modelled on the independent audit literal implementation without calling it. Reject malformed Unicode at the future JS→PG boundary before pg can substitute U+FFFD. No hashing, truncation, normalization or compression assumption. Index due work on (connectionId,status,nextAttemptAt,rowId), lease recovery on (connectionId,status,leaseUntil,rowId), inbox page on (connectionId,recipientUserId,deliveredAt,outboxId).
* RecipientInboxRow maps to public.recipient_inbox. outboxId UUID is PK/FK to outbox.rowId RESTRICT/NO ACTION. It stores an immutable copy of the exact normalized public intent columns above, deliveredAt NOT NULL and nullable readAt. No connectionGeneration or scheduling/lease fields. Derive status DELIVERED and readState from readAt in the public mapping. Enforce finite times, deliveredAt >= notBefore, readAt >= deliveredAt when present. Only a narrowly owned AFTER UPDATE transition trigger on the outbox inserts this row from NEW on first confirmed delivery; it has no caller-supplied recipient/payload arguments. Unique outboxId plus immutable natural key gives 1:1 delivery uniqueness. A repeat of DELIVERED is a no-op; a mismatching preexisting projection must fail. Outbox state and inbox materialization commit/roll back together. Repeated reads retain the first confirmed timestamp; an inbox update trigger rejects clearing or changing an established readAt. P10-005's future conditional delivery ack thereby performs the inbox insert in its own transaction.
* NotificationWorkerGrantRow maps to public.notification_worker_grants, an empty operator-provisioned binding table keyed by (databaseRole,connectionId); binds principalUserId and the same five connection fields by FK, organization/principal membership by FK, expected generation, active flag. Use a safe bounded role-name type; no login/password/token storage. This small grant is necessary for a service identity: a self-selected GUC plus possession of a common worker role would otherwise authorize arbitrary tenants. Do not reuse SOURCE_BUILD, sync, or audit grants. No production rows/login provisioning.

## Receipt invariants

Use bigint in [0,9007199254740991] for attempt and [1,9007199254740991] for eventRevision. UTC finite timestamptz(3), canonicalize already validated EventTimestamp instants to milliseconds in future adapters (reject sub-ms significant digits before PG rounds). Explicitly constrain timestamp range to the supported UTC four-digit contract years including JS year 0000 where representable (PG 1 BC); never emit infinity. notBefore >= createdAt. Non-null nextAttemptAt >= notBefore, leaseUntil > notBefore, deliveredAt >= notBefore. Use explicit IS NULL/IS NOT NULL and total Boolean predicates to avoid CHECK silently accepting SQL UNKNOWN.
    
| State | Attempt | nextAttemptAt | leaseToken / leaseUntil | deliveredAt / read |
|---|---|---|---|---|
| PENDING | >=0 | required | both null | null / UNREAD |
| LEASED | >=1 | null | both required, token is ExternalId | null / UNREAD |
| DELIVERED | >=1 | null | both null | required / persisted inbox readAt |
| FAILED | >=1 | nullable | both null | null / UNREAD |
| UNKNOWN | >=1 | nullable | both null | null / UNKNOWN |

P10-001 permits a retry time for FAILED and UNKNOWN. Do not coerce uncertainty into delivery or infer readAt. Enqueue starts only PENDING, attempt 0, nextAttemptAt=notBefore, unset lease/delivery. Require immutable intent/generation, nondecreasing attempts, terminal DELIVERED and LEASED→DELIVERED only. Infrastructure constraints establish valid shapes. Future worker adapters enforce holder token, expiry, fencing and retry/claim policy with guarded, parameterized updates.
