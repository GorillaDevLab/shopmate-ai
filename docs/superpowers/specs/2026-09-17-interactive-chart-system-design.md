# 统一交互图表升级

## 已确认范围

升级所有现有图表：销售折线/面积图、商品与门店横向条形对比图、饼图/环形图。主页、组件库预览和 AI 对话中的图表预览复用一致的图表组件。保留内容自适应布局和冷静/灵动模式，不调用真实 AI 或线上数据库，不虚构指标。用户补充要求：扩展受限查询协议，让 AI 按场景推荐合适图种，同时允许用户在兼容图种中手动选择。

## AI 场景选图与用户控制（新增范围）

现有协议的 visualization 和生成 kind 仅允许 pie/report；按日期查询仍复用 pieResult，最多十二项，并可按值排序，不能直接用于完整三十天趋势。因此不仅修改提示词，还需要升级契约、查询执行结果和保存格式的兼容处理。

- 生成入口默认为“自动推荐”，也可指定折线、面积、条形、环形或报告。AI 在同一次受限查询生成中识别指标、维度、范围和呈现意图，不为选图额外发起第二次 LLM 请求。
- 推荐规则由服务端校验兜底：时间序列推荐折线/面积，分类比较推荐条形，可加总非负指标的构成分析允许环形，综合摘要使用报告。
- 用户明确指定兼容图种时优先遵从；不兼容时给出中文原因和可选图种，而不是把商品名称当作时间轴或对平均客单价计算占比。
- 时间序列单独返回按日期升序排列的完整受限区间，不沿用分类 Top N 截断。保留现有时间范围限制；若超出可承载范围，明确提示，不静默丢失日期。无记录的日期仅在业务查询已确认无销售时作为零值，查询缺失不能假装为零。
- 已返回结果的兼容视图切换在前端完成，不调用 AI，也不重新查询数据库。改变指标、分组或时间范围属于新查询，需要用户主动提交。
- 推荐解释使用数据类型与查询意图生成简短说明，如“按日期查看变化，推荐折线图”，不额外生成经营结论。
- 所选呈现方式随用户显式保存看板持久化；兼容旧 pie/report 查询和已有组件，版本变更必须提供读取迁移与回归测试。
- 不开放任意 SQL 执行。继续用经过字段/聚合/维度白名单校验的 DSL、服务端商家隔离和现有鉴权。

## 方案

选择共享格式化、配色、选择状态规则与轻量 SVG/CSS 图形。相比仅美化静态图，此方案增加可操作的信息反馈；相比直接引入完整图表库，复用现有折线交互和契约，减少迁移风险。本期不新增散点图、雷达图或后端尚未提供数据的图种。

参考 Shopify Polaris Viz 的环心信息、图例联动与 Other 分组，以及分析页的主要指标加明细呈现；保留本项目紫色主题和两种外观，不照搬品牌样式。

## 共用视觉与交互

- 标题、时间范围、单位与图表操作保持一致层级。金额使用千位分隔；紧凑摘要可缩写，详细读数保留完整精度。
- 同一结果内商品在图例、条形、环形之间保持相同颜色；不能只靠颜色表达选中状态。
- 鼠标悬停与键盘聚焦提供临时高亮；点击或触屏选中可持续查看，清除后恢复整体。数据更新后已不存在的选择回退，不显示旧读数。
- 选中详情放在卡片内部稳定区域，避免浮层越出屏幕。移动端不用悬停才能获取信息。
- 加载、错误、空、单项、全零和大量条目均有明确表现；无数据不绘制误导性图形。
- 375px、平板与桌面响应式；展开明细后由现有内容自适应网格重排。

## 折线/面积图

- 复用当前按时间选点、参考线、密集数据键盘/拖动交互，增加统一的选中日期与金额详情、突出点和绘图区层次。
- 提供折线/面积切换，二者显示同一组数据。时间顺序不因金额排名改变。
- 日期标签适度抽稀，但所有点仍可操作。零值正常落在零线，不能冒充缺失值；空数组显示空态。
- 绘图保留真实数据折点，不使用可能造成超调或假趋势的平滑曲线。仅在已有数据范围内显示摘要，不额外构造环比/同比。

## 柱状/条形图

- 现有横向对比图显示排名、数值和可加总指标的占比；平均值/比例类指标不伪造总和占比。
- 按值降序稳定排序，条形与名称共同形成可点击行；选中行明显高亮。
- 零基线和最长条比例一致，不用装饰改变数值关系；长名称可换行，金额不被拆碎。
- 项目过多时默认显示前五项并提供展开全部；条形比较的比例基准仍使用完整返回结果。

## 环形图

- 使用真正中空的 SVG 环形图；中心显示“当前展示合计”，选中后显示对应项金额/数量及占比。
- 正常摘要显示前五项加“其他”，其他精确聚合剩余返回项；展开后可查看每项。明确合计仅涵盖查询返回范围，不称为全店总额。
- 扇区与图例双向高亮，统一稳定颜色；图例可键盘操作，扇区不增加大量重复 Tab 停靠点。
- 非可加总指标保留禁止环形的现有约束；总和为零时不绘制满环。

## 动效

- 初次出现时使用一次性的线条/柱条/圆环入场；切换视图采用短淡入或尺寸过渡，不旋转、不反复播放。
- 冷静模式仅保留轻量交互反馈；灵动增加低强度渐变与选中光晕。减少动态效果偏好关闭非必要动画。
- 图表重绘不触发请求，hover/focus 不改变布局尺寸，避免 ResizeObserver 反馈循环。使用 transform/opacity 为主，SVG 入场在有限时长内完成。

## 实现边界

公共工具负责排序、分组、格式化和配色；公共交互展示负责选中详情与图例行；图种组件只负责自身几何与操作。AI 对话预览改为使用同一图表入口，不能因为升级而再次执行生成请求。现有销售趋势组件与新时间序列结果共用绘图能力。所有外部文本通过 React 文本节点渲染，不使用 HTML 注入。后端与契约改动仅服务于场景选图和正确返回时间序列，不改变商家基础数据表。

## 验收

1. 单元测试覆盖合计、前五/其他、排序、颜色一致性、零值、选择与数据更新回退。
2. 交互测试覆盖鼠标、键盘、点击、展开/收起和图种切换；现有聊天、布局测试继续通过。
3. 模拟请求的浏览器验证主页、组件库与 AI 预览，375/768/1440px，两种外观和减少动态效果；检查图例联动、可读性和无溢出/卡片重叠。
4. 通过前端测试、TypeScript、目标文件 ESLint、Prettier 和生产构建后才交付。
5. 本轮独立分支 feat/interactive-chart-system，基于已合并的 PR #176；不自动推送、合并或部署。
6. Mock LLM 测试覆盖自动推荐、明确指定图种、不兼容请求、无效结构；后端测试覆盖用户隔离、时间升序、三十天不被截为十二天和旧版查询兼容。实际供应商调用不在测试范围。
7. UI 测试确认兼容图种切换不发请求，选定视图显式保存并在重新加载后恢复。
