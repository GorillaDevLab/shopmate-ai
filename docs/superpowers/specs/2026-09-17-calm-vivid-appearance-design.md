# 冷静 / 灵动：看板双模式设计

## 已确认目标

- 顶部入口名称固定为「冷静 / 灵动」。
- 首次访问、无有效设置时默认冷静；主动选择的模式保存在当前浏览器，刷新恢复。
- 冷静模式简洁、清晰、专注工作，关闭装饰动画、流光与玻璃效果。
- 灵动模式大胆开放主页背景和所有看板组件的装饰，不只改变品牌色。
- 切回冷静不删除灵动设置，再次切回恢复原装饰。
- 不调用真实 AI 或付费生图，不操作线上数据库。

## 方案与取舍

选择共享 CSS 材质层：用渐变、伪元素、透明度和 transform 动画提供彩色玻璃、流光与光晕。效果覆盖统一卡片容器，不改每种图表的数据逻辑。

纯静态换肤难以满足灵动效果；每卡独立 WebGL 会增加渲染资源、上下文和交互复杂度。本期不采用每卡 WebGL，不承诺复刻截图的真实折射算法。

## 用户体验

### 顶部切换

顶部提供可键盘操作的双选按钮，选中状态以文本、底色和 aria-pressed 表达。375px 下保持可见、可点击，避免挤占页面主要操作。模式切换不改变看板布局、业务筛选、AI 会话或未保存草稿。

### 灵动装饰面板

外观设置在灵动模式下提供装饰入口。右侧抽屉桌面展示；移动端使用受视口高度约束的面板，内容可滚动，保存操作可达。

- 编辑对象：主页、全体组件、或单个组件；组件列表使用真实标题和稳定 card.id。
- 预设：青蓝、粉橙、蓝橙、银灰四套明显不同的材质配色。
- 自定义：主色、辅色、暗部颜色；材质透明度、光晕强度、动画速度；动画开关。
- 实时预览：面板内展示当前对象的材质，不改变销售数字或伪造图表数据。
- 保存后应用；取消关闭不覆盖已保存装饰。
- 单卡设置覆盖全局组件设置；新增组件默认继承全局；可恢复单卡继承，也可确认后恢复全部默认。
- 全体组件操作明确清除单卡覆盖时必须二次确认。

### 视觉边界

灵动主页使用鲜明的多色流光背景、玻璃表面、彩色边缘光与层次阴影；卡片材质允许独立配色。

装饰只作用于容器底层，使用 pointer-events: none，不能覆盖拖拽、缩放、菜单、链接与输入。文字与图表保留足够不透明的内容底层；颜色选到极端值时仍保持可读对比度。风险红、成功绿等业务语义色不被材质覆盖。

已有紫色 / 陶土色保留为基础品牌主题，与冷静 / 灵动这一材质模式分离。

## 架构与持久化

- 保持现有主题模块职责，新增独立的版本化 appearance 配置与校验模块。
- 模式、主页材质、组件默认材质、按 card.id 的单卡覆盖分开建模。
- 设置保存在单独的 localStorage key。本期仅当前浏览器，不承诺跨设备、跨浏览器或账号同步；面板明确说明。
- 基础主题初始化脚本旁恢复已校验的模式，避免首屏闪到错误模式。
- 所有颜色只接受完整十六进制颜色，数值限制范围，预设使用白名单。拒绝任意 CSS、URL、脚本和样式文本。
- 存储缺失、格式损坏或版本未知时回退冷静和默认材质；存储失败明确提示本次设置仅临时生效。
- 共享 React 状态连接顶部入口、设置面板、主页与统一卡片容器。单卡材质不写入经营查询 DSL，不变更服务端布局契约。
- 本地覆盖数量设上限，超限给出明确提示，避免无限增长。

## 性能与无障碍

- 不为每张卡启动 JavaScript 动画循环；共享 CSS 动画规则。
- 冷静模式彻底停用装饰动画。页面隐藏、系统 prefers-reduced-motion 或用户关闭动画时显示静态材质。
- 不支持 backdrop-filter 时回退到可读的不透明渐变背景。
- 面板有标题、关闭按钮、焦点管理、Escape 退出；取消和保存语义明确。
- 加载、无可选组件、存储失败都有可见状态。

## 验收

1. 新浏览器首次显示冷静；切换与刷新恢复正确，没有明显主题闪烁。
2. 主页、指标、趋势、库存、热销、AI 图表及报告均支持灵动材质。
3. 单卡自定义与全局继承正确；切换冷静再切回不丢设置。
4. 取消不保存，恢复默认需确认；存储损坏和存储失败可恢复且有提示。
5. 装饰不改变图表数值、统计范围、卡片次序与草稿状态。
6. 桌面和 375px 浏览器验证滚动、按钮可达、拖拽和设置面板；检查静态与减少动态效果。
7. 用模拟接口测试，不请求真实模型、不写线上数据。单元测试、TypeScript、Lint 和格式检查通过后交付。
