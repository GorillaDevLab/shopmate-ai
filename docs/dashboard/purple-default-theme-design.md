# 经典紫色默认主题设计

## 目标

将“经典紫色”设为看板的默认界面主题，同时尊重用户已保存在当前浏览器中的明确选择。

## 行为边界

- 浏览器没有 `shopmate-theme` 记录时，首屏使用 `purple`。
- 已保存 `purple` 或 `terracotta` 时，继续恢复该值，不做迁移或覆盖。
- 存储值无效时，安全回退到 `purple`。
- 浏览器存储不可读时，安全回退到 `purple`，并继续显示现有的存储错误提示。
- 服务端输出的 `<html data-theme>` 同步改为 `purple`，避免 hydration 前闪现陶土色。
- 两个主题选项及用户切换能力保持不变。

## 实现位置

- `apps/web/src/app/theme.ts`：调整白名单解析和首屏初始化脚本的默认值。
- `apps/web/src/app/layout.tsx`：调整服务端 HTML 默认主题。
- 现有主题单元测试：先验证旧实现失败，再覆盖无存储、无效存储、存储异常及显式陶土选择。

## 非目标

- 不删除“暖灰陶土”。
- 不覆盖已有用户选择。
- 不改变经营数据、用户布局或后端模型。
- 不把数据库迁移问题隐藏为前端默认布局；本次加载故障已通过补齐本地数据库迁移单独解决。

## 验收

- 新浏览器首次访问直接显示经典紫色且无主题闪烁。
- 外观设置中经典紫色默认选中。
- 用户切换为暖灰陶土后刷新仍保持陶土色。
- 主题测试、前端测试、TypeScript、Lint 与生产构建通过。
