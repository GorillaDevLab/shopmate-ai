# 统一助手工作区部署与验收

## 本次变化

继续使用现有 DeepSeek 配置。前端统一使用 `POST /api/v1/ai/assistant/run`；侧栏和 `/chat` 共享会话、草稿与执行状态。旧 JSON 聊天接口仍保留。图表由受权限和结构化查询校验约束的工具返回，用户点击加入后仍需在看板确认保存。

会话仅保存在当前浏览器，按服务端确认的用户和商家隔离。最多 30 个会话、每个 100 条消息、总量 2 MiB；不支持跨设备同步。退出登录或收到未认证响应后清理本地记录。浏览器禁用存储时显示未保存提示，不偷偷丢弃历史。历史内容不作为经营数据证据。

## 部署顺序

1. 同时部署当前分支的 API 与 Web；无需修改数据库或运行迁移/seed。
2. API 增加受认证保护的 `GET /api/v1/auth/me` 和上述流式 POST。已有登录 Cookie、商家隔离和工具权限不变。
3. 参考 `deploy/nginx/shopmate-ai.conf.example` 增加流式接口的精确 location：关闭响应缓冲和缓存，读取超时至少 200 秒。示例 API 地址为 `127.0.0.1:3001`；容器部署请换成实际 API upstream。不要开放绕过认证的代理路径。
4. 由有服务器权限的组员先运行 `nginx -t`，通过后再 reload。本任务只修改配置示例，未修改线上 nginx。
5. Web 的 `API_BASE_URL` 仍指向正确 API。前后端版本不一致时 UI 会明确提示，不会退回旧接口再次收费请求。

## 执行和费用边界

- 进度来自实际接收、工具查询及整理阶段，不展示模型内部思维链；不是逐字输出。用户可以停止，取消信号传到 DeepSeek SDK，之后不再开始下一次工具调用。
- 已发送的模型请求可能已经计费；停止不代表退款，也不保证数据库正在执行的只读查询立即停止。
- 不自动重新提交断线/超时请求。保留原有有界工具循环与数据校验修正逻辑；一次用户问题仍可能包含多次必要模型调用，不能宣传为“一问只计费一次”。
- 纯粹“换成饼图”等兼容视图切换复用已有结果，不再调用模型。
- 去重与单用户执行锁是单 API 进程内、请求 ID 保留 10 分钟。多实例部署或进程重启不提供跨实例幂等保证；扩容前应增加共享去重存储。不会自动恢复后台任务。

## 验收（不调用付费 AI）

单元测试和本地浏览器验收均使用模拟 Provider/API。覆盖身份验证、跨账号隔离、取消与迟到结果、查询条件继承、文案、图表确认加入、草稿、NDJSON 分片及非法响应。生产构建检查前端不含已知不兼容的正则后行断言和类静态初始化块。

人工浏览器检查：1440px 完整页、520px 右侧栏、375px 手机视口，两种工作台模式；长文表格、图表滚动、历史开合、Esc 焦点恢复、跨页面会话延续。没有实际 iOS 16.2 微信真机测试，也没有验证真实模型的回答质量。

线上免 AI 检查可以先确认登录后 `/api/v1/auth/me` 返回当前账号身份、未登录返回 401，以及静态脚本正常加载。不要用聊天请求做免费健康检查，它可能调用收费模型。
